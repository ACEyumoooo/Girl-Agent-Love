# 世界观文件规范

`game/seikai.md` 管这个世界的边界，人物卡管某个人的边界。两份都在每批请求里注入，世界观在前、人物卡在后。

写世界观只做一件事：让模型知道什么不能发生。写不进规则里的形容词都是废话。

## 文件长什么样

纯 Markdown，没有 frontmatter。按下面七节写，顺序别改，引擎按标题定位「当前局势」这一节回写摘要。

```markdown
# 世界观

## 一句话

靠海的旧城区，一所每年级只有两个班的高中。

## 时代与地点

二〇〇〇年代初，南方沿海小城。没有智能手机，联络靠家里的座机和纸条。

## 世界规则

- 学校里没有电梯，天台只在午休和放学后开放
- 校服是硬性规定，改校服会被年级主任叫去谈话
- 学生打工要家长签字，多数人没签
- 台风季在六月到九月，停电很常见

## 主要场所

- `day_classroom` / `dusk_classroom` / `night_classroom`：二楼靠走廊尽头的教室
- `day_rooftop` / `dusk_rooftop` / `night_rooftop`：天台，水箱后面是唯一晒不到太阳的角落
- `day_gate` / `dusk_gate` / `night_gate`：校门，门卫认得迟到的脸
- `dusk_street` / `night_street`：一条坡道，坡底的便利店开到十一点

## 人物关系

- 「我」：高二，走读
- 她：转学生，和「我」同桌
- 班主任：四十多岁，管得松，但记性很好

## 禁忌与尺度

- 不写自杀、自伤、成瘾的具体方法
- 不写真实的学校名、地名、人名
- 亲密接触停留在牵手和靠肩，不写露骨内容

## 当前局势

故事刚开始，还没有人知道对方的底细。
```

## 每一节写什么

**一句话** 给整部作品定调。模型每次注入先读这一行，决定用词是轻还是重。

**时代与地点** 决定物件的年代感。写了二〇〇〇年代初，就不能出现智能手机和短视频。

**世界规则** 是硬约束，写成能判定的句子。写"氛围压抑"模型没法执行，写"天台只在午休和放学后开放"它就能让剧情绕开。

**主要场所** 的每一项要和 `picture/scene/` 的文件名对齐，时间前缀只用 day / dusk / night，否则模型会想到一个没有背景的地方。

**人物关系** 只写关系，不写人物细节。人物细节全部放到各自的 `persona/<名字>.md`。

**禁忌与尺度** 是硬边界，模型和玩家都不能越过。

**当前局势** 由引擎维护。每 `GALGAME_REINJECT_EVERY` 拍（默认 40），引擎把最近剧情压成一段摘要写进来，只改这一节，前面六节原样保留。你也可以手动改，改完下一次注入就生效。

## 引擎怎么用它

- 每批请求的 system prompt 顺序是：世界观 → 女主角人物卡 → 生成格式与规则
- 每 `GALGAME_REINJECT_EVERY` 拍重新注入一次，防止模型写久了忘设定
- 切换模型时强制重新注入，计数器归零
- 开了 `GALGAME_SUBAGENTS=1` 时，每个角色的子智能体也各自拿到完整世界观，但只拿到自己的人物卡

## 写完自检

- 随便抽一句正文，有没有和「世界规则」冲突的地方？
- 「主要场所」里有没有 `picture/scene/` 里找不到的地方？有就补图，或者把那一项删掉。
- 「人物关系」里有没有混进人物性格？有就挪进人物卡。
- 「当前局势」是不是还在写开头？开局就该换成现在的时间和处境。
