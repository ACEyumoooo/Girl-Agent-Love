# BGM 用法

文件按数字 id 命名，比如 `1.mp3`、`2.ogg`。下面按实际放的文件改，没有的 id 删掉。

## 1

情绪：平静、日常。

什么时候用：普通教室对话、早读前、放学后闲聊、没有冲突的相处。

不要用：争吵、告白、追逐、突然的坏消息。

## 2

情绪：轻快。

什么时候用：玩笑、打闹、关系变好、心情放松。

不要用：沉默、尴尬、独处。

## 3

情绪：安静、低落。

什么时候用：一个人待着、回忆、关系变冷、说不出口的话。

不要用：热闹的多人场景。

## 4

情绪：紧张。

什么时候用：冲突、被发现、时间压力、要说重话之前。

不要用：日常闲聊。

## 0

停止 BGM。只在需要完全安静时用。
