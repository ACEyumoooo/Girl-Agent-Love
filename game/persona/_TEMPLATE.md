# 角色名字

写清她是谁、几岁、性别、和「我」是什么关系。这一段会直接注入模型。
设定可以参考 bangumi、萌娘百科之类的资料，但不要照搬受版权保护的长段原文。

文件名用 frontmatter 的 `id`，例如 `persona/aya.md`。立绘放 `game/picture/standing/<id>/<立绘id>.webp`。

## 声音

只有开语音时用：音色、语速、口音、习惯。比如「年轻女声，声音偏轻，语速慢，句尾会弱下去」。

OpenAI 兼容接口会把这一段当音色提示（instructions）；阿里云百炼文生声不支持自由描述，要在 frontmatter 里加 `voice_name` 选固定音色（如 `Cherry`、`Serena`、`Ethan`），不写就用 options 里的 `GALGAME_VOICE_NAME`。
